# 05 · 合规红线

> 这一页不是建议，是**上线前必须过**的检查项。踩了红线的后果比不火严重得多。

## 1. 事实：不要写与素材冲突的结论

最常见、也最致命的一类。

**真实例子**：某品牌事故共创的官方口径写「车身安然无恙」，但定损记录与车主公开发言都显示
这台车已被保险**推定全损**。照抄「安然无恙」＝把刀递给评论区（"全损叫安然无恙？"）。

**正确做法**：先列出素材能佐证的事实，再写结论，且结论必须能被素材接住。

改写示例：

| 不要写 | 改成 |
|---|---|
| 车身安然无恙、完好无损 | 车没保住，人保住了 |
| 车没事 | 乘员舱没有垮 / 车主零受伤 / 未侧翻 |
| 救了一命 | 关键时刻守住了最后一道线 |

**自检动作**：把文案里每一个「结论句」拿去对照素材，问一句「这条能被截图证明吗」。
证明不了的，删或降级成限定表述。

## 2. 绝对化用语

广告法与平台规则双重敏感，尤其汽车、医疗、金融：

```
最强 唯一 第一 顶级 绝对安全 零风险 保命神器 必买 吊打 完胜
刀枪不入 陆地堡垒 吊打一切 …
```

「公路坦克」这类绰号可以**引用**（引用官方说法/网友说法），但不要自己下判断句。
「同级最长」这类必须带**限定条件**且来自官方口径。

## 3. 数字与来源

- 事故类：**不编**车速、载重、撞击角度、伤亡人数、责任判定。
- 测试类：区分**官方测试数据**与**本次真实事故**，文案里要明确说清，别混写。
  （例："25 吨侧翻压顶是官方公开测试，不是这次事故"）
- 认证类：不写「中保研五星」「中汽研五星」，除非有对应报告；官方口径「五星安全设计标准」要原样引用。

## 4. 隐私

- 车牌、姓名、手机号、VIN、人脸、人脸倒影 一律打码。
- 截图里**已经打过码的区域**：不许裁掉、不许还原、不许锐化重绘。
- 事故类内容不做「人肉进度条」（不追问车主身份、不引导网暴对方司机）。

## 5. 不贬损、不引战

- 不评价其他品牌「撞了会怎样」。
- 不对货车司机/对方做道德审判（责任由交警认定）。
- 不做地域、性别、职业对立。

## 6. 不刷量、不互赞

本仓库**不含**任何刷量、批量注册、指纹伪装、验证码绕过能力，也不建议手搓。
互动率超过自然区间（一般 1%~3%）会触发风控，轻则限流重则封号。

## 7. AI 声明

- 抖音：`自主声明 → 内容由AI生成`
- 视频号：`含AI生成内容`

AI 配音、AI 字幕、AI 生图、数字人出镜，都属于应声明范围。
上游工具会自动勾选，**不要取消**。

## 8. 素材授权

- 只用自己拍的、官方给的、或明确授权可商用的素材。
- 官方测试视频用于「引用/评测」要注明来源，不要剪成像是自己实测的。
- BGM 不要用未授权的商业音乐：本仓库 `assets/bgm/` 只放你确认可用的曲子。

## 9. 平台条款

自动发布本质是**用你的登录态操作你自己的账号**。各平台对自动化的态度不同：

- 使用前自行确认目标平台的服务条款；
- 单账号发布频率保持人类水平（本仓库不做批量并发）；
- 出现验证码、实名验证等人工环节时，由**账号本人**完成，不要试图绕过。

## 10. 上线前 30 秒自检表

- [ ] 文案里每个结论句都能被素材证明
- [ ] 没有与「全损/失效/事故后果」相冲突的表述
- [ ] 没有绝对化用语
- [ ] 官方测试与真实事故已明确区分
- [ ] 所有打码区完整保留
- [ ] 没编数字、没判责任
- [ ] AI 声明已勾选
- [ ] `#话题` 里有必带话题
- [ ] 标题长度在平台上限内（抖音 ≤30、视频号短标题 7~15）
- [ ] 封面图一眼能看懂，且不含误导性对比
